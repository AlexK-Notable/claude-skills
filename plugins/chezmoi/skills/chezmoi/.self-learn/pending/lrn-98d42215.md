## Trigger
About to run `chezmoi cd` in a non-interactive shell (Claude Code Bash tool, scripts, cron jobs)

## Instruction
Never use `chezmoi cd` there — it spawns an interactive child shell and blocks until the command times out (observed: 2m Bash-tool timeout, exit 143). Resolve the path instead: git -C "$(chezmoi source-path)" <cmd>, or cd "$(chezmoi source-path)" within the same compound command
