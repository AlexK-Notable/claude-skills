# Domain: Project Directory

## Protected Paths (Default)

When organizing a project directory, protect:

```json
[
  "<target>/src",
  "<target>/.git",
  "<target>/docs"
]
```

Adapt based on project structure. Always protect `.git` — losing git history is catastrophic.

## Exploration Commands

```bash
# Overview of project structure
ls -la <target>/

# Size breakdown
du -sh <target>/*/ 2>/dev/null | sort -rh

# Hidden directories (often caches/configs)
du -sh <target>/.* 2>/dev/null | sort -rh

# Git status (if git repo)
git -C <target> status --short 2>/dev/null

# Find build output directories
find <target> -maxdepth 3 -type d \( -name "build" -o -name "dist" -o -name "out" -o -name "target" -o -name "__pycache__" -o -name "node_modules" -o -name ".next" -o -name ".nuxt" \) 2>/dev/null

# Find large files
find <target> -type f -size +10M -exec ls -lh {} \; 2>/dev/null | sort -k5 -rh
```

## Project-Specific Categories

### Build Artifacts (Safe to Delete)
These are regenerated by running the build command:

| Directory/Pattern | Generated By | Rebuild Command |
|-------------------|-------------|-----------------|
| `node_modules/` | npm/yarn/pnpm/bun | `npm install` |
| `target/` (Rust) | cargo | `cargo build` |
| `build/`, `dist/`, `out/` | Various build tools | Project-specific |
| `__pycache__/`, `*.pyc` | Python | Automatic on import |
| `.next/`, `.nuxt/` | Next.js/Nuxt.js | `npm run build` |
| `.tox/`, `.nox/` | Python test runners | `tox`/`nox` |
| `*.egg-info/` | Python packaging | `pip install -e .` |
| `.parcel-cache/` | Parcel bundler | `parcel build` |
| `.turbo/` | Turborepo | `turbo build` |
| `coverage/`, `.nyc_output/` | Test coverage tools | Re-run tests |

### Dependency Caches
| Directory | Manager | Safe to Delete? |
|-----------|---------|----------------|
| `node_modules/` | npm/yarn/pnpm | Yes (reinstall) |
| `.venv/`, `venv/` | Python venv | Yes (recreate) |
| `vendor/` | Go/PHP | Yes (re-vendor) |

### IDE/Editor Files
| Directory/File | Editor | Action |
|----------------|--------|--------|
| `.idea/` | JetBrains | Delete unless shared settings |
| `.vscode/` | VS Code | Keep if `settings.json` has project config |
| `*.swp`, `*.swo` | Vim | Safe to delete |
| `.DS_Store` | macOS | Safe to delete |

### VCS-Aware Checks

Before deleting anything in a git repo:
1. **Check for uncommitted changes**: `git status`
2. **Check for untracked valuable files**: `git ls-files --others --exclude-standard`
3. **Verify .gitignore covers build outputs**: Build dirs should be gitignored

## Project Cleanup Patterns

```bash
# Remove all __pycache__ directories recursively
find <target> -type d -name "__pycache__" -exec rm -rf {} + 2>/dev/null

# Remove node_modules (ask first — slow to reinstall)
rm -rf <target>/node_modules

# Remove Rust target directory
rm -rf <target>/target

# Clean build artifacts but preserve source
find <target> -maxdepth 2 -type d \( -name "build" -o -name "dist" \) -exec rm -rf {} + 2>/dev/null
```
