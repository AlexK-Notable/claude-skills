## Trigger
About to sandbox-copy a uv Python project (cp -r, rsync) to run mutation tests, kill checks, or any experiment against the copy

## Instruction
Delete the copied venv first (rm -rf <copy>/.venv) and re-sync in the copy — the copied venv's editable install still points at the ORIGINAL source tree, so anything run inside the copy silently executes the original's code and every mutation appears to change nothing
